# Responsive JavaScript Form Validation Project

A beginner-friendly frontend project built using HTML, CSS, and JavaScript.

This project demonstrates how to create a modern responsive form with real-time validation, regex-based email and password checks, and dynamic UI feedback.

---

## 🚀 Features

- Responsive design
- Real-time form validation
- Email format validation using Regex
- Strong password validation
- Error and success states
- Dynamic input border styling
- Modern UI design
- GitHub Pages deployment ready

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
